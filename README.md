# Position Sizer

Futures position size calculator (MNQ default, $50k default balance). Single static page, no build step,
works offline once installed. Settings are saved in the browser's local storage on your device only.

## Put it on your iPhone
1. Publish with GitHub Pages: repo -> Settings -> Pages -> Deploy from a branch -> `main` / `(root)`.
2. Open `https://<your-username>.github.io/<repo-name>/` in **Safari** on the iPhone.
3. Share button -> **Add to Home Screen**.

## Updating
Edit `index.html`, bump `CACHE` in `sw.js` (e.g. `position-sizer-v2`), commit and push.
